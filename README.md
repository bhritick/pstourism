## 🚀 Installation & Setup

### Prerequisites
- XAMPP (or any local server)
- Git
- Modern web browser

### Local Development Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd pstourism
   ```

2. **Start XAMPP**
   - Open XAMPP Control Panel
   - Start Apache server
   - (Optional) Start MySQL if using database features

3. **Access the website**
   ```
   http://localhost/pstourism/
   # or
   http://127.0.0.1/pstourism/
   ```

4. **File Structure**
   - Place files in `C:\xampp\htdocs\pstourism\` (Windows)
   - Place files in `/opt/lampp/htdocs/pstourism/` (Linux)

### Production Deployment

1. **Upload files** to web server
2. **Configure .htaccess** for URL rewriting
3. **Update canonical URLs** to production domain
4. **Submit sitemap** to Google Search Console
5. **Verify Google Analytics** tracking
6. **Test all pages** for broken links

## 📝 Notes for Developers

### Important Files
- `index.html` - Homepage with main schema markup
- `sitemap.xml` - Keep updated with new pages
- `.htaccess` - Server configuration & redirects
- `manifest.json` - PWA configuration

### Common Tasks
- **Adding new package:** Copy existing package template, update content, add to sitemap
- **Updating prices:** Search and replace across relevant files
- **Adding gallery:** Create gallery page, link from package page
- **SEO update:** See GitHub issues for prioritized tasks

### URL Naming Convention
Current: `destination-duration-description.html`
